    راهنما

    هر چیزی که برای خوندن عددهای PacketYellow لازم داری.

    پینگزمان رفت و برگشت یه بسته. زیر ۶۰ عالی، ۶۰ تا ۱۲۰ قابل قبول، بالای ۱۲۰ برای بازی بد.
    جیترمیزان نوسان پینگ. بالای ۲۰ms یعنی لگ‌های لحظه‌ای و صدای قطع‌ووصل تو تماس.

    داشبورد زنده

    هر ثانیه یه نمونه از هدف انتخاب‌شده گرفته میشه و ۹۰ ثانیه‌ی آخر روی نمودار میاد. خط‌های قرمز یعنی بسته گم شده.

    خودکار (پیش‌فرض): برنامه هر چند ثانیه شبکه رو چک می‌کنه؛ اگه VPN / پروکسی روشن باشه خودش میره روی HTTP و اگه خاموش باشه برمی‌گرده روی TCP.
    TCP: زمان دست‌دادن TCP رو می‌سنجه. بدون VPN دقیق‌ترین حالته.
    HTTP · مناسب VPN: روی یه اتصال باز، درخواست کوچیک می‌فرسته. چون از پروکسی/تونل سیستم رد میشه، پینگ واقعی از پشت VPN رو نشون میده.

    با فیلد «هدف دلخواه» می‌تونی هر آدرسی رو پایش کنی، مثلاً سرور بازی خودت.

    تست سایت‌ها و معنی هر وضعیت
    بازسایت کامل جواب داد.
    کُندباز شد ولی بیشتر از ۲.۵ ثانیه طول کشید.
    تحریم / محدودسرور جواب داد ولی دسترسی رو بست (کد 403 یا 451)، معمولاً تحریم IP ایران.
    فیلتر (DNS)DNS آدرس 10.10.34.x (صفحه‌ی پیوندها) رو برگردوند.
    فیلتر (SNI/TLS)اتصال TCP برقرار شد ولی موقع HTTPS قطع شد؛ فیلترینگ روی نام دامنه.
    اتصال برقرار نشدحتی TCP وصل نشد؛ IP مسدوده یا سرور خاموشه.
    DNS پیدا نکرددامنه resolve نشد. DNS دیگه‌ای امتحان کن.
    تایم‌اوتتا ۱۰ ثانیه جوابی نیومد.

    ستون پینگ برای سایت‌ها زمان TCP به سرور سایته. اگه پشت VPN باشی و TCP مستقیم ممکن نباشه، پینگ HTTP نشون داده میشه (با علامت HTTP).

    پینگ بازی‌ها چطور سنجیده میشه؟

    بیشتر سرورهای بازی فقط UDP هستن و بدون دسترسی ادمین نمیشه مستقیم پینگشون کرد. برای همین برای هر بازی، منطقه‌هایی که سرورهاش اونجاست (مثلاً بحرین، امارات، فرانکفورت) سنجیده میشه؛ پینگ تو بازی تقریباً همون پینگ تا اون شهره.

    بازی‌هایی که سرور TCP واقعی دارن مستقیم پینگ میشن: Supercell (پورت 9339)، Battle.net (پورت 1119)، Riot (پورت 5223)، Minecraft (پورت 25565)، و CS2 / Dota 2 از لیست زنده‌ی سرورهای Steam.

    سرورهای مشترک فقط یک بار پینگ میشن، پس تست ۵۰ بازی هم سریعه. سرور خاص خودت رو از «بازی / سرور دلخواه» اضافه کن.

    VPN و کانفیگ‌ها (مثل v2rayN / Hiddify)

    هسته: کانفیگ‌های VLESS / VMess / Trojan / SS با Xray اجرا میشن (همون هسته‌ی v2rayN و پنل‌های 3x-ui و Marzban، پس هر کانفیگی که اونجا کار کنه اینجا هم کار می‌کنه). Hysteria2 / TUIC و حالت TUN با sing-box. بار اول «دانلود هسته‌ها» رو بزن (هر دو از GitHub خودشون، روی هم حدود ۲۵ مگ). اگه GitHub باز نشد، xray.exe و sing-box.exe رو دستی بذار تو «پوشه‌ی هسته».

    اتصال واقعی: بعد از وصل شدن، برنامه از داخل تونل یه درخواست واقعی می‌فرسته؛ فقط اگه جواب بیاد «متصل» نشون میده. اگه سرور کار نکنه، به‌جای اتصال الکی دلیلش (فیلتر، کلید REALITY اشتباه، گواهی، DNS ...) رو می‌گه.

    افزودن: لینک‌ها (هر خط یکی) یا لینک ساب رو بچسبون و «افزودن» رو بزن. ساب‌ها گروه جدا دارن و با ⟳ آپدیت میشن؛ حجم مصرفی و تاریخ انقضا هم اگه پنل بفرسته نشون داده میشه.

    تست: «پینگ TCP» فقط باز بودن پورت سرور رو می‌سنجه. «تست واقعی» از داخل خود کانفیگ یه درخواست واقعی می‌فرسته (مثل Real delay تو v2rayN)؛ کانفیگی که اینجا عدد بگیره واقعاً کار می‌کنه.

    حالت‌ها: «پروکسی سیستم» پروکسی ویندوز رو خودکار تنظیم و موقع قطع برمی‌گردونه. «TUN» همه‌ی برنامه‌ها و بازی‌ها رو از تونل رد می‌کنه و باید برنامه با Run as administrator باز شده باشه. «فقط پورت» فقط SOCKS/HTTP روی 127.0.0.1 باز می‌کنه.

    پشتیبانی: VLESS (REALITY، Vision، XHTTP، WS، gRPC، HTTPUpgrade، TCP-HTTP)، VMess، Trojan، Shadowsocks (+2022)، SOCKS با Xray · Hysteria2 (با port hopping)، Hysteria، TUIC، H2 و کانفیگ‌های insecure با sing-box. Fragment برای کانفیگ‌های TLS پشت CDN که با فیلترینگ SNI قطع میشن.

    پورت و DNS: همه اختیاریه. پورت خالی = 2080 (اگه اشغال بود یه پورت آزاد خودش انتخاب میشه). DNS تونل خالی = 1.1.1.1 با DoH. DNS مستقیم خالی = DNS سیستم. می‌تونی بنویسی 8.8.8.8، 8.8.8.8:53، https://dns.google/dns-query یا tls://1.1.1.1. «برگشت به پیش‌فرض» همه رو ریست می‌کنه.

    جزئیات کانفیگ: روی هر ردیف کلیک کن؛ پایین جدول همه چیز (آدرس، پورت، SNI، Host، Path، Fingerprint، ALPN، Flow ...) مثل v2rayN نشون داده میشه و می‌تونی کانفیگ هسته رو به‌صورت JSON کپی کنی.

    موقع بستن برنامه اتصال قطع و پروکسی سیستم برگردونده میشه؛ حتی اگه برنامه کرش کنه، دفعه‌ی بعد که باز بشه پروکسی درست میشه.

    بازی دلخواه و پایش زنده

    قدم ۱: تو تب بازی‌ها «افزودن بازی / سرور دلخواه» رو بزن و یه اسم بذار. قدم ۲: اگه بازیت تو «الگوی آماده» هست (کانتر، SA-MP، Minecraft، FiveM) روش کلیک کن تا پورت و روش خودش پر بشه. قدم ۳: آدرس سرور رو بنویس (مثلاً 1.2.3.4:27015). قدم ۴: دکمه‌ی ⚡ «تست» رو بزن؛ اگه عدد سبز/زرد اومد درسته. مطمئن نیستی کدوم روش؟ «خودکار» رو بذار. آموزش کامل با دکمه‌ی «آموزش» داخل همون پنجره هست.

    دکمه‌ی پایش زنده (کنار هر بازی تو جدول نتایج، یا تو پنجره‌ی ویرایش) همه‌ی سرورهای اون بازی رو هر ثانیه همزمان پینگ می‌کنه: پینگ لحظه‌ای، میانگین، جیتر، پکت لاس و نمودار ۶۰ نمونه‌ی آخر برای هر سرور.

    تست سرعت

    با ۴ اتصال همزمان از Cloudflare دانلود و با ۳ اتصال آپلود می‌کنه. ۱.۵ ثانیه‌ی اول هر مرحله حساب نمیشه چون TCP هنوز به سرعت کامل نرسیده. آپلود فقط بایت‌هایی رو می‌شمره که سرور واقعاً دریافت کرده.

    هر تست حدود ۱۰۰ تا چند صد مگابایت مصرف می‌کنه (بسته به سرعتت). روی اینترنت حجمی حواست باشه. دکمه‌ی توقف هر لحظه کار می‌کنه.

    تست DNS و DNS دلخواه

    DNS فعلی سیستمت خودکار به لیست اضافه میشه. با فرم بالای جدول هر DNS دیگه‌ای (IPv4، IPv6، یا با پورت غیر ۵۳) اضافه کن؛ ذخیره میشه و دفعه‌ی بعد هم هست.

    ستون «پاسخ»: واقعی یعنی برای youtube.com آدرس واقعی داد، فیلترشده یعنی صفحه‌ی فیلتر رو داد.

    برای تغییر DNS ویندوز: Settings ← Network ← Wi‑Fi یا Ethernet ← DNS server assignment ← Edit.

    VPN و اپراتورهای مختلف

    برنامه با همه‌ی اپراتورها (همراه اول، ایرانسل، مخابرات، شاتل، رایتل، ...) کار می‌کنه: همیشه IPv4 رو ترجیح میده چون IPv6 خیلی از اپراتورها ناقصه، تایم‌اوت‌ها برای خطوط موبایل بلندتره و تست‌ها محدود و موازی اجرا میشن تا DPI اپراتور مسدودشون نکنه.

    VPN خودکار تشخیص داده میشه (اینترفیس تونل، حالت TUN / Fake-IP، IP دیتاسنتری، WARP). در حالت TUN آدرس‌های 198.18.x.x جعلی هستن و پینگ TCP بهشون بی‌معنیه؛ برنامه این رو علامت می‌زنه. پشت VPN از حالت HTTP استفاده کن.

    اطلاعات شبکه IP خروجی واقعی (بعد از VPN) رو نشون میده، نه IP داخلی.

    لاگ و گزارش خطا

    بخش «لاگ» (کلید 9) همه‌ی خطاها و اتفاق‌های مهم برنامه رو با ساعت دقیق نشون میده: قطع شدن پایش، رد شدن درخواست‌های تست سرعت، سرویس‌های IP که جواب ندادن، خطاهای رابط کاربری و ... . عدد قرمز کنار منو یعنی خطای جدید داری.

    برای گزارش باگ، «کپی همه» یا «ذخیره» رو بزن و متن رو بفرست.

    SA-MPGTA San Andreas Multiplayer و open.mp. پورت پیش‌فرض 7777.

    «تست» بزن، بعد ذخیره

    دکمه‌ی کنار هر سرور همون لحظه پینگ رو نشون میده. اگه عدد اومد یعنی درسته؛ «ذخیره و پایش زنده» رو بزن تا هر ثانیه نمودارش رو ببینی.

    جواب نمیده؟ آدرس و پورت رو دوباره چک کن، روش رو عوض کن (مثلاً از ICMP به Steam)، و اگه VPN روشنه یه بار خاموشش کن؛ پینگ بازی از پشت VPN معنی نداره.
